# 点击补色百关题库 v0.6

唯一运行题库为 `data/levels/levels.v0.6.json`，schemaVersion `4.1.0` / contentVersion `0.6.0`，玩法 `click-fill`，输入 `tap`。旧运行题库与旧导出档不再保留。

每关上方是固定提示色与空缺渐变轨道，下方是乱序候选。先点选颜色，再点空槽完成放置。已放色可移动到另一轨道空槽，或取回下方任意候选空槽。候选槽不压缩，点击分页，标准每页18格，小屏可适配12或6格；色块没有永久绑定的归还位置。

`trayHomeByTile` 只描述开局的初始索引，供作者证解与固定seed复现，不参与运行时归还位置限制。数据同时声明 `trayHomeByTileRole: initial-only`、`shuffle.stableHomeSlots: false` 及 `candidateSlots: any-empty`，避免与旧规则混用。

## 确定性受约束洗牌

全库至少4块候选；生成器通过固定seed的xorshift32/Fisher–Yates拒绝采样，最多4096次，超限直接导出失败，不回退为答案顺序。顺序基准是导出cells中的非锚点目标序，单轨则为路径遍历序。

每关必须满足：

- 候选池不是目标正序，也不是目标倒序。
- 至少75%的候选初始位置偏离其目标序位置。
- 最长连续正向或反向目标段不超过2块。
- 候选邻接中的连续目标对比例不超过35%。

`shuffleQuality` 记录候选数、错位数与比例、最长连续段、目标相邻对数与比例、接受尝试次数及上限。验证器重算实际质量，并提供正序、倒序和伪造质量记录的损坏数据探针。随机打乱本身不能证明难度或视觉合理性，仍需试玩。

## 倒计时与证解

所有100关都使用倒计时，时间耗尽失败。L001为45秒；其余 `T=clamp(45+N×s,45,240)`，N为初始空槽数，章节系数s依次6、6、5、5、4秒。自愿完成激励视频每次续时30秒，每局最多两次；取消、未完成或失败不奖励，也可免费重开。

有效放置次数只用于表现积分；没有步数失败条件。取回、取消与无效点击不增加该统计，撤销不返还时间或库存。N为无道具精确补全的最低有效放置数，初始候选索引证解只证明可以补全，不证明真人能在倒计时内完成。真实广告位尚未开通，未配置时不能伪造观看奖励。
