# 点击补色百关目录 v0.4

唯一运行题库：`data/levels/levels.v0.4.json`。上方只预填固定锚点，下方为固定归位槽的候选色。
N为初始空槽/候选色数量，也是无道具精确目标的最低有效放置数。前四关不限步，第五关起B=N+max(2,ceil(N×章节比例))+舒缓加成。
允许免费取回；落位与移到另一空槽各扣1步。占用格不可覆盖。人工试玩、真机显示和商业效果待验收。
