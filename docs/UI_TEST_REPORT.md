# UI 0.2.0-ui.1 实际验收

日期：2026-10-27。引擎 Cocos Creator 3.8.8。以下截图来自实际 Cocos Web 运行画面，390×844；不是 image 效果图。抖音模拟器与手机运行仍待导入新包确认。

## 交付变化

- 加载：image 竖版插画、真实资源阶段进度、完整健康游戏忠告、可点开的开发期适龄说明。阅读说明时不自动进入首页。
- 首页：image 自然色彩岛屿插画，开始/继续、关卡、教程、收藏、设置；首次不自动进第一关。
- 教程：三页图形点击练习，选色填空、改放、取回原候选槽、步数与道具；局部状态，不改正式进度或库存。结束后继续已有盘面，不隐式重开。
- 关卡：移除常驻教学话术，12 个 image 公共图标统一视觉；单页不显示分页；更大的首关色块、紧凑候选托盘、图标道具与数量徽标。保留纯 HEX 色面。

## 实际走过的路径

1. 资源完成后进入首页；打开教程并退出，回到首页。
2. 教程点候选再点空槽，显示完成；下一页选已填色块改放到另一空槽，再返回其原候选槽；进入第三页道具介绍。
3. 加载页预览显示插画、完成进度与完整声明；打开适龄说明、关闭并返回首页。
4. 独立测试第一关，点候选再点空槽，进入通关弹层；不计入正式进度。
5. 独立测试第100关，6×6 盘面、32候选、分页与图标道具显示完整。
6. 最终页面浏览器 error 日志为空。已恢复临时视口设置，并保留本机测试页。
