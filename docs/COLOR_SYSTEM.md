# 《拾色之间》自然配色规范

日期：2026-10-27。当前唯一颜色规范。用户已认可的百关自然配色继续保留，交互按 [点击填空设计](GAME_DESIGN.md) 执行，当前题库为 `data/levels/levels.v0.4.json`。

## 1. 数据与艺术来源

100 组自然四角种子位于 `data/palettes/nature-palettes.v1.json`。逐关手工选择具体 HEX，使用原创自然主题，不宣称照片采样、商业色卡或权威传统色标准。四角顺序为左上、右上、左下、右下；最终实际角点与受控变换记录在关卡配色元数据。

配色服务于轨道推理。每个真实格位只有一个目标颜色，横纵路径来自一致二维色场，交点不分别配两种答案。采用 Oklab 四角插值与统一色域处理；不逐格随意调饱和度或光照破坏连续关系。

当前点击玩法改版保留已接受的目标 HEX、轨道、提示块和自然主题，重新生成仅含提示块的开局、固定候选池、填入证解与预算。候选池中的每枚颜色与其最终目标必须完全一致。

自然也有土色与柔和色，但不能反复回到相似的低色度中心。明亮、清透、浓郁、鲜活、深邃与柔和穿插出现。深邃不等于灰，柔和不等于无色。

大多数组合用相邻色相构成一条方向，再以另一色向提供第二条关系，避免四种互补颜色在中心抵消成灰泥。跨色惊喜题如极光、欧泊和星云须逐盘检查中心及交点。

## 4. 可复现生产

编辑艺术种子 → 生成关卡实际 HEX → 检查色域、路径连续性、候选色差、交点一致、实际邻关距离与主题覆盖 → 绘制精确色值图 → 客户端与手机复核。题库工具位于 `tools/levels/`，图鉴与报告位于 `docs/levels/`。

邻关检查使用导出 HEX 集合的双向最近邻平均 Oklab 距离与亮度、色度统计。主题名不同不等于颜色不同；远距离同一主题可以回归，不要求百关颜色两两互斥。

自动数字用于发现问题，不是通用人眼阈值。未通过手机试玩前，不把最低色差、明度捷径检查或证解回放称为唯一感知答案证明。

## 5. 显示与审阅

游戏中按数据的纯 `#RRGGBB` 绘制，完全不透明，盘面、候选、参考层和收藏一致。不加内部高光、渐变、纹理、发光、环境色和滤镜；不通过降低透明度表示不可选。固定提示、辅助锁和选中标记都放在色块外。

先看整章是否有冷暖、浓淡和亮暗节奏；再看连续三关是否明显切换；再看单盘路径和交点是否合理；再看下方乱序候选能否分辨；最后在手机不同亮度下复核。UI 保持轻暖中性，不用装饰背景给题目颜色染色。

审阅图是从真实 HEX 绘制的内容检查工具，不能代替实际游戏页面、触摸命中与宿主平台验收。当前人工审美、替代解判断和真机辨色继续保持待验证状态，完成后记录设备和关号。
