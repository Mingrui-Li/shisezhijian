# 可用于登记系统的说明文字
## 开发目的
为用户提供以颜色观察和渐变关系判断为核心的休闲益智体验，支持分关挑战、操作辅助和游戏进度保存。
## 面向领域
移动互联网休闲益智游戏。
## 软件主要功能
提供五章一百关颜色填空挑战，支持候选色块选择、填入、改放、归还和撤销；具备倒计时、判胜结算、关卡解锁、动画教程、音效与动效设置；按通关表现发放积分，并支持点睛、窥色、续时道具及积分购买；使用本地双副本保存进度、钱包和盘面，提供激励视频奖励适配与去重处理。
## 软件技术特点
采用Cocos Creator与TypeScript实现，规则状态转换与界面分层；以版本化JSON组织百关数据，校验色块守恒；采用双副本读回验证保存进度，并以请求台账处理奖励去重及迟到回调。
## 软件功能与当前接入状态
已实现客户端点击填色、百关题库、倒计时、积分、道具、商店、教程与本地保存。
激励视频已实现接口适配与奖励规则，但当前真实广告位未配置。真实广告展示与真机完整交互仍待验收。
上文功能说明按现有实现撰写，不将测试模拟写成真实平台广告投放。
## 版本填写依据
项目 package.json 与运行配置一致标识为1.1.0，因此登记版本采用V1.1.0。
题库0.6.0属于内部内容版本，不作为本次软件登记版本填写。
已有公开可访问的预览链接不据此自动认定首次发表；本稿按申请人确认的未发表情况填写。
具体字段限字数及可选分类以办理时登记系统显示为准，可在保持事实一致的前提下压缩文字。
