## 现行核心接口

`game/assets/scripts/core/index.ts` 是不依赖Cocos或抖音SDK的纯TypeScript模块。UI只负责选择、取消与反馈，核心接收确认动作；未提交选择不进入盘面存档。时钟只在Playing推进倒计时。

| 动作 | 参数 | 结果与消耗 |
| --- | --- | --- |
| place | poolIndex, toCellId | 候选色放入上方空槽，记录1次有效放置；刚取走的候选槽留空 |
| move | fromCellId, toCellId | 已填色块移到另一轨道空槽，记录1次有效放置 |
| returnToTray | fromCellId, toPoolIndex? | 收回指定候选空槽；未指定时自动选择可用空槽；不增加放置数、不返时间 |
| undo | 无 | 恢复最近盘面、候选实际占位和辅助锁，不退时间、道具与额度 |
| locate | 无 | 提取正确块腾空，错误占位块收回可用候选空槽，再归位辅助锁；不绑定原槽 |
| peek | pathId, nowMs | 一路参考3秒，期间冻结盘面与倒计时 |
| addTime | 无 | Playing消耗续时，增加30秒 |
| elapse | deltaMs | Playing扣正整数毫秒，到0进入Failed，不越界 |
| purchaseProp | prop | 原子扣积分、加库存；与持久化协调，失败回滚 |

占用格不覆盖、不交换；原提示块和辅助锁不可移动。候选槽位置固定但色块可以收回任意空槽，`trayHomeByTile`仅用于描述初始索引与作者证解，不是运行时归还约束。保存和撤销按实际当前占位验证守恒。

轨道目标正确且候选为空即通关；有效放置只参与成绩，不触发失败。剩余1毫秒时已提交的通关仍成立，失败后冻结解题动作，可查看分页、复活、重开或离开。

全100关计时，L00145秒；其余 `T=clamp(45+N×s,45,240)`，章节s依次6、6、5、5、4。视频复活+30秒，每局最多2次，保留盘面和实际候选占位。

- 专用WinPanel只显示已提交成绩和到账金额，按钮消费相同业务接口；实际排版另作UI验证。
