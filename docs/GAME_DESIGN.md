# 《拾色之间》游戏设计

日期：2026-10-28。本文为当前唯一玩法与运营规则；对应 Cocos Creator 3.8.8 竖屏抖音小游戏及唯一运行题库 `data/levels/levels.v0.6.json`（schema4.1.0，contentVersion0.6.0），当前客户端1.1.0已完成自动回归、构建和Web验证，抖音工具首页与官方预览已取证，手机和真实广告另行验收。实际构建、网页、开发者工具和真机的验收状态分别记录，不以规则文档代替运行证据。

## 1. 体验与主流程

玩家先点击下方待选颜色，再点击上方轨道空槽，补全自然渐变。画面温馨、轻快；趣味来自辨色、路径和交点关系。五章各二十关，共一百关。第13–100关保留已认可的目标色值、轨道、交点与提示块；前12关在原自然主题下重做结构与颜色采样，形成更有判断空间的起步阶梯。

主流程为加载 → 首页 → 开始/继续 → 关卡 → 专用胜利卡 → 下一关。胜利卡由庆祝插画、超大得分、积分到账条、用时/操作统计和主次分明的按钮组成；不再把结算堆成多行文字。首页始终存在，提供关卡、动画教程、道具屋与设置入口。首次启动也先进入首页。关选显示所有关号，锁定状态同时用色彩和锁标记表达；完成当前最前未通关关，开放下一关。

每关都有倒计时。超时后失败，玩家可主动看激励视频保留盘面续玩，或免费重开。通关表现换成积分，积分用于购买道具。主收入来自自愿选择的激励视频，不在解题中自动插播。

## 2. 点击填空与判断

开局上方只有固定提示块，其余位置为空槽；其余色块全部进入下方候选区。候选槽位置固定，取走后留空，不压缩、不自动重排；已放入上方的色块可以收回下方任意空槽，没有永久绑定的归还位置。交点只占一个真实格位。

| 操作 | 结果 | 计分用有效动作数 |
| --- | --- | ---: |
| 点候选色块 | 选中；再次点它可取消 | 0 |
| 选中候选，再点上方空槽 | 填入；刚取走的候选槽留空 | 1 |
| 点已填入、未锁定色块，再点另一空槽 | 改放到新空槽 | 1 |
| 选中已填块，点任意下方空槽 | 收回该候选空槽 | 0 |
| 选中已填块，点“放回待选区” | 自动收回一个可用候选空槽 | 0 |
| 点占用格、固定块、无效区域或取消选色 | 不覆盖、不交换、不改盘面 | 0 |

有效动作数只用于通关表现评分，没有动作次数耗尽的失败条件。候选与盘面中的每枚色块必须恰好出现一次。普通正确色块不自动锁定，不实时显示逐块对错或正确率。原始提示块与点睛辅助锁不可移动，使用不同块外标记。

每次提交动作后立即判胜：全部目标颜色正确、候选区为空即通关。满盘但颜色错误保持进行中，玩家可归还一块后继续调整；倒计时仍会消耗。计时事件将剩余时间减至零时进入失败，之后不能继续提交填色动作。已经提交成功的通关不被随后的计时回调覆盖。

失败后冻结填入、改放、归还、撤销和道具使用；可查看候选分页、复活、免费重开或返回。关闭失败弹窗仍是失败状态。

撤销恢复上一次盘面动作、候选槽的实际占位及辅助锁，不返还已用时间、有效动作数、道具库存、本局道具额度或广告权益。点睛可作为完整事务撤销盘面；窥色与续时不进入盘面撤销栈。免费重开创建新 attemptId，恢复本关初始盘面、候选顺序和倒计时，重置本局额度，不退已消耗库存、不重发赠礼。

## 3. 百关难度与时间

| 章节 | 关号 | 逻辑规模 | 初始待填数 N | 主要判断 |
| --- | --- | --- | ---: | --- |
| 初见 | L001–L020 | 7–16 格 | 5–12 | 明暗、色序、基础分组 |
| 流转 | L021–L040 | 16–20 格 | 11–15 | 转折、多路归属与先后 |
| 交汇 | L041–L060 | 20–25 格 | 15–20 | 共享交点的两向约束 |
| 微澜 | L061–L080 | 25–30 格 | 20–25 | 大候选池、相近色系、组合判断 |
| 合鸣 | L081–L100 | 30–36 格 | 25–32 | 密集交点与综合规划 |

前12关从转弯单路逐步过渡到横纵约束：第1关7格/5候选，第2–3关各9格/7候选，第4–5关3×3双向题各5候选，第6–8关12格/8候选，第9–11关13–15格/9–11候选，第12关4×4/12候选。具体轨道以当前题库及作者改版源为准，不能用旧版首关单空槽代表新版。

每关初始时间统一按以下公式生成到题库：

```text
L001 = 45 秒
其余关卡 = clamp(45 + N × k, 45, 240) 秒
k：第一、二章为 6；第三、四章为 5；第五章为 4
```

难度来自题目规模、路径约束、相对思考时间与候选归属，不通过临场缩短时间或改变颜色制造卡点。每关必须有无需道具、无需广告的可执行证解。时间参数需要真人首次完成率、超时率与误触数据继续校准，自动回放只证明逻辑可解。

开局候选必须经过固定seed的受约束洗牌，不采用答案正序或倒序；至少75%候选偏离目标序位置，最长正向/反向连续段不超过2，目标相邻对比例不超过35%。最多尝试4096次，不能满足就拒绝导出，不回退到答案排列。质量记录由验证器重算，随机本身不证明真人难度。

上方轨道与下方候选是一个紧邻的解题功能区，整组垂直居中；短题两者间距 44 设计单位，大盘间距 32。390 宽设计坐标下尽量保持单块至少 44；最大 6×6 盘面与 32 候选采用固定位置的候选槽分页，最多每页18格，短屏降为12或6。分页按钮跟随候选区，不固定漂到页底，不消耗额外时间奖励或动作数。

只在真实关卡的可解题状态推进倒计时；明确暂停的首页、教程、参考与视频等待状态不推进。切后台保存剩余时间；恢复不重置本关初始时间。界面应清楚显示本关剩余时间，不在暂停状态继续接受解题输入。

## 4. 积分、购买与道具

积分为本地持久化的非现金游戏资源，不可充值、提现。新玩家初始各拥有一个道具；L004 首通后额外赠点睛3、窥色2、续时1；每章首次全部通关，每种再赠1。重开、重复结算、回玩和存档恢复不重复赠送。

通关成绩介于100至200分，当前计算规则为：

```text
效率分 = round(50 × min(1, N / max(N, 有效动作数)))
时间分 = round(50 × clamp(剩余时间 / 初始时间, 0, 1))
辅助扣分 = 10 × (本道具使用总次数 + 本次复活次数)
通关成绩 = max(100, 100 + 效率分 + 时间分 - 辅助扣分)
本次积分入账 = max(0, 本次成绩 - 该关历史最佳成绩)
```

首次通关历史最佳为0，因此入账100–200分；回玩只补发提高纪录的差额，持平或降低不再入账，避免重复刷简单关。前12关使用独立成绩代次 `expanded-0.6`；升级保留已获钱包积分、库存与通关权益，旧版简单题的成绩不会阻挡新版首次挑战奖励。同一新版代次内仍严格按最佳差额入账。道具或复活增加的时间不会让时间分突破50。胜利卡展示本次成绩与积分到账；总积分保留在首页和道具屋，减少结算信息堆叠。

| 道具 | 积分价格 | 效果 | 每次尝试上限 |
| --- | ---: | --- | ---: |
| 点睛 | 120 | 归位并固定一枚未正确安置色块 | 2 |
| 窥色 | 80 | 选择一条色路，查看目标参考3秒 | 1 |
| 续时 | 100 | 当前进行中的倒计时增加30秒 | 2 |

道具屋可从首页进入，也可从道具详情进入购买；显示积分余额、库存、价格及效果。购买把扣积分、加库存写为一个事务；保存失败回滚本次扣分与库存，显示失败原因，不留下只扣分未得道具的状态。购买不自动使用；每局使用上限不会被额外购买绕过。

点睛先从候选或错位盘面提取正确块，释放其当前位置，再把目标槽的错误占位块收回下方可用空槽，最后将正确块归位并设辅助锁；不要求回某个原槽。取块、腾空、安置整次原子提交，保持色块守恒。没有效果时不消费。窥色是独立参考层，不写答案，3秒后或切后台关闭；期间不能提交盘面动作。续时只能在进行中使用，失败后不能用库存替代复活。

## 5. 广告与失败闭环

三个激励视频入口分别为：

| 位置 | 玩家明确选择的奖励 | 限额 |
| --- | --- | --- |
| 超时失败面板 | 保留当前盘面、候选、辅助锁及历史，增加30秒 | 每次尝试最多成功2次 |
| 通关结算 | 将本次实际积分入账再补发一份 | 每关最多成功1次，且本次入账必须大于0 |
| 缺货道具详情 | 指定道具库存增加1，再由玩家自行使用 | 每次尝试最多成功1次 |

失败面板明确写“时间到了”，显示“看视频续玩 +30秒”、剩余复活次数、免费重开、返回。广告未完整观看、取消、加载失败或平台无填充都不发奖、不消耗成功额度，不清除已整理盘面。广告等待期间锁定重复请求。未配置 adUnitId 时明确显示“广告暂未开放”，不能冒充观看成功或悄悄发放复活。

每次请求持久化 requestId、attemptId、关卡版本、奖励类型和奖励量。平台明确确认完整观看后，奖励、次数与去重记录一起保存；重复回调只发一次。已确认但迟到的复活回调不能直接修改新盘面，保存为一次性待用权益；领取仍受当前尝试复活上限约束。取消或未知结果不变成权益。

双倍积分针对本次入账增量，不重复发完整历史最高分；资格按该关当前成绩代次判断。成功领取标志与积分入账一起保存；跨页或重开后的迟到成功回调仍按请求中冻结的奖励发放一次，不重新计算。

用户目前未开通广告位；保留完整接入、按钮和不可用提示。取得真实广告位ID后才能验证真实激励视频展示、完整观看和平台奖励回调，不把本地功能通过描述成已产生广告收入。

## 6. 视觉、教程与适龄

首页用自然花园插画，标题、副标题有独立净空；游戏页的轨道和候选共用轻柔面板。所有实际颜色使用题库纯HEX，不叠图片色调。道具用统一图标、数量徽标和详情解释，不用常驻教程句子挤占解题区。

教程是三页自动循环原生动画：点选填空、改放归还、点睛/窥色/续时。手指移动、选择高亮、色块飞入清楚解释操作；每页约5–6秒循环，可以随时上下翻页。教程只使用本地演示节点，不读写正式盘面、积分或库存；减少动效时用分阶段静态展示。

用户已与抖音确认适龄8+。加载页左上安全区下放置可点击8+标志，打开适龄说明；同时显示完整健康游戏忠告、真实进度和自然彩带插画。适龄说明与后台配置保持一致，实名认证与防沉迷的实际接入另做平台验证。
