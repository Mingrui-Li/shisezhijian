# 《拾色之间》游戏设计

日期：2026-10-27。当前唯一玩法与商业规则。适用题库：`data/levels/levels.v0.4.json`。首轮参数须随可玩版本试玩校准，文档不代表已经完成客户端或平台验收。

## 1. 游戏体验

一款竖屏、温馨轻快的颜色填空小游戏。上方是保留少量提示色块、留有空槽的渐变轨道；下方是待选色块。玩家**先点击选色，再点击空槽放入**，通过颜色的先后与交点关系补全渐变。

趣味来自观察、比较和逐步整理后的完整色彩。观察不计时；有效填入与改放计步。前期建立直觉，后期用更丰富的路径、较多候选与更少的纠错余量形成挑战。有限道具帮助跨过卡点，失败后可主动看视频保留盘面继续，也能免费重开。

首发为五章、每章二十关，共一百关。主线顺序开放，已完成关可回玩。先不引入倒计时、体力、金币、付费礼包、抽卡或每日任务。

## 2. 一套点击规则覆盖百关

所有关卡都从“仅提示块已在上方，其余块在下方”的状态开始。候选池与上方空槽一一对应，交点是一个真实格位，不复制成两枚色块。

| 点击操作 | 结果 | 步数 |
| --- | --- | ---: |
| 点击下方可用色块 | 选中；显示块外轮廓 | 0 |
| 选中后点击上方空槽 | 放入该槽，候选原槽留空 | 1 |
| 点击已填入、未锁定的色块 | 选中，准备调整 | 0 |
| 选中已填色块，再点击另一空槽 | 从原槽移到该空槽 | 1 |
| 将选中已填色块放回自己的候选原槽 | 取回；此前花费步数不退 | 0 |
| 取消选中、重复点原位置、点轨道外、点固定提示块 | 无盘面变化 | 0 |
| 选中后点已占用格 | 不覆盖、不交换、不扣步 | 0 |

未选色时点击可选色块即选中；点击另一枚下方候选可以切换选色。已有选择时点上方占用格仍拒绝；想选另一上方色块，先取消原选择。选中态不承担移动提交。实际扣步只发生在成功填入或改放的原子动作上，动画不再次扣步。

候选槽有固定 `homeIndex`，不因取走、取回或换页重新排序。取回只回自己的原槽，不能把块放到另一枚色块的候选槽。为避免跨页寻找，选中已填色块时提供“放回待选区”按钮，直接回原槽；这是免费取回的同一操作入口。

普通色块放对后不自动锁住，不实时标红、标绿，不显示正确率。只有原始提示块与点睛产生的辅助锁不可移动。这样玩家仍需要自己判断色路，而不是逐格试答案。

### 填满与结算

每次有效动作、道具或奖励提交后，依次检查：

1. 所有槽位已填，颜色符合认可目标：进入通关。
2. 尚未通关且剩余步数为零：进入失败。
3. 其余情况继续。

最后一步刚好完成必须通关。满盘但颜色未完成、仍有步数时保持进行中，轻提示“再看看颜色的衔接”；可免费取回一块，腾出空槽再调整。失败后冻结选色、填入、取回、改放、撤销和解题道具，保留盘面与候选分页查看。关闭失败面板不会恢复操作。

判胜按颜色或已登记的等价组判断，不依赖色块实例编号。任何新增认可解须进入题库并增加内容版本；不能用运行时宽松色差临时放行错误布局。

### 撤销与重开

撤销恢复上一条盘面动作的格位、候选槽和辅助锁，不返还步数、道具库存、道具已用次数或广告权益。取回也可撤销；撤销本身不进入动作栈。窥色与续步没有可回滚的盘面操作，不进入盘面撤销栈。界面首次说明“撤销不返还步数”。

免费重开产生新 `attemptId`，恢复固定候选顺序、提示块和初始预算，清空本次动作历史；不返还已消耗库存，不重复发礼物。进行中重开要简短确认，失败后的免费重开可直接执行。

## 3. 五章一百关的阶梯

轨道、提示块和自然配色沿用已经认可的百关内容；开局、候选池、证解和预算统一按点击填空生成。难度来源从颜色归属、路径关系、交点判断和有限纠错余量共同形成，不能只靠让颜色越来越接近。

| 章节 | 关号 | 轨道规模 | 初始待填数 N | 主要能力 |
| --- | --- | ---: | ---: | --- |
| 初见 | L001–L020 | 3–16 格 | 1–11 | 明暗、色序；从单路到基本分组 |
| 流转 | L021–L040 | 16–20 格 | 11–15 | 转折、多路候选归属与先后顺序 |
| 交汇 | L041–L060 | 20–25 格 | 15–20 | 共享交点，两方向必须同时成立 |
| 微澜 | L061–L080 | 25–30 格 | 20–25 | 大候选池、相近色系、组合判断 |
| 合鸣 | L081–L100 | 30–36 格 | 25–32 | 密集交点与多路约束，综合规划 |

每章以四个五关段落逐步组合能力。章内第 8、12、16 关为舒缓关：保留本章的题目规模，增加两步余量，不把后章突然退回三块短线。第 20 关为章末综合题。第 1–4 关不限步，分别教学选色填入、色序、取回改放和交叉关系；第 5 关引入限步，第 4 关首次完成后发道具。

舒缓没有倒计时；较难关卡也允许停下来比较颜色。教程、难题和章末题都显示同一套上轨道、下候选的空间关系，不能在后章切换成另一种主操作。

### 下方候选池

标准长屏每页最多18槽（6列×3行），第19–32枚在第二页。安全区较大或短屏按可用高度降为每页12或6槽，始终通过明确的左右分页按钮与实际页码切换；不足一页按实际数量显示。分页免费，可随时查看，失败态与道具参考态也允许查看；暂停的是解题动作。

选中状态跨页保持，页面不因放入或取回自动重排。屏幕较窄时仍优先保住单块触达大小，不能为了把 32 枚全挤在一页而缩成难点的小格。上方完整轨道与当前页候选同屏；不让玩家通过滚动整个页面寻找空槽。

### 初始预算

设 `N` 为本关开局空槽数量。每次有效填入只能消除一个空槽，因此无道具的最少有效动作恰好为 `N`；证解由候选池逐块填入目标，必须能回放。

L001–L004 为不限步，预算为 `null`。L005 起采用：

```text
B = N + max(2, ceil(N × r)) + soothingExtra
r = 0.70 / 0.50 / 0.35 / 0.25 / 0.18（第一至第五章）
soothingExtra = 2（章内第 8、12、16 关）；其他为 0
```

例如普通题 N=11/15/20/25/32 时，预算分别为 19/23/27/32/38 步。预算全部导出到题库，客户端不临场变更。第一遍参数旨在提供递减的相对纠错空间，尚未经过失败率校准。

取回免费，重新填入仍需一步，所以纠正误判有明确代价。所有关卡必须存在预算内、无需道具或广告的证解。道具与广告帮助保住一次尝试，不用于修补无解预算。

## 4. 三种有限道具

库存全局保存，数量为非负整数。首次赠送在 L004 首通后仅一次发放 3/2/1；每章首次全部通关，每种再赠 1。重开、回玩或恢复存档不能重复领取。

| 道具 | 效果 | 每次尝试上限 |
| --- | --- | ---: |
| 点睛 | 归位一枚未正确安置的色块，设辅助锁，不扣步 | 2 |
| 窥色 | 选择一条色路，展示目标参考 3 秒，然后恢复原盘面 | 1 |
| 续步 | 进行中增加 5 步；失败态不能使用 | 2 |

点睛是一条原子事务：目标槽若被错误色块占用，先把占位块送回其固定候选原槽；再把所选色块从候选池或错位槽填入目标并锁住。占位块不会直接进入另一上方槽。没有可执行效果时不消费。撤销可恢复整个事务的盘面与辅助锁，但不退库存和本局使用次数。

窥色在单独的“参考”层显示所选路径，交点仍只有一种目标颜色。预览期间不允许解题操作，不写回当前答案；可提前关闭，切后台立即关闭，恢复时不重发 3 秒。分页仍能查看。续步只加剩余步数，不重置已花步数或初始预算。

道具详情写清效果、库存和本局剩余次数，再由玩家点击“使用”。库存为零、当前处于进行中且该道具还有使用次数时，可选择视频领取 1 枚；先入库存，再由玩家决定使用。本次尝试补货视频最多成功领取一次，不能换个道具重复领。不可用原因用文字区分，不能只把按钮变灰。

## 5. 失败、复活与收入

主收入入口是玩家主动选择的激励视频：保留失败盘面补步，以及缺少道具时补货。首轮不在观察过程中插入强制广告；不自动播放首次失败视频。

失败标题可用“就差一点点”，说明必须明确“步数用完了，颜色还为你留着”。提供：

- “看视频 +X 步”，同时展示本局剩余复活次数；不可用时说明原因。
- “免费重新挑战”和“返回选关”，保持可读可点。

每次尝试最多视频复活两次，奖励为 `max(5, ceil(N × 0.20))` 步。例如 N=25 补 5 步，N=32 补 7 步。复活保留盘面、候选原槽、辅助锁和动作历史；不重新打乱或清空已花步数。两次使用同一奖励公式。

道具补货一次与复活两次分别计数，成功发奖才消费对应次数，总计最多三次。取消、未完整观看、加载失败都不发奖、不扣次数、不改变盘面。失败态不能用续步库存绕过复活。

### 广告奖励必须可靠

每个请求先持久化 `requestId + attemptId + levelContentVersion + type + amount`。等待期间禁止重复请求。平台明确确认完整观看后，发奖、计数与请求去重在同一存档事务提交；重复回调只发一次。

回调迟到且原尝试已被重开或离开时，不修改新盘面。已确认奖励写入一次性待用权益，后续按其原奖励量领取，并遵守当前尝试的复活上限；不因跨关重复计算或重复发放。未知观看结果不当作成功。视频失败时保留免费重开和返回。

开发环境可以明确模拟成功、取消和失败；正式抖音版本未配置广告时显示未配置，不得用模拟奖励冒充真实广告接入。

## 6. 页面与长期进度

首次完成必要启动流程后直接进入 L001；后续启动显示首页的“继续拾色”。主流程为加载 → 首页/继续 → 游戏 → 通关 → 下一关；另有章选关选、道具详情、失败复活和设置。

通关反馈是很短的色路收束与轻音效，随后展示自然配色名和下一关。无需复杂角色、场景或长剧情。已完成关保存一张由真实色值绘制的色谱卡，收藏展示可在基础闭环稳定后接入，不作为首关门槛。

主线完成当前最前未通关关才解锁下一关。返回选关不自动越关；免费重开与回玩已开放关始终存在。设置提供声音、触觉和减少动效，重启后保留。

## 7. 试玩校准与签收

记录每关开始/完成/失败、有效填入与改放、取回次数、道具使用、复活发起及成功、免费重开、候选翻页和离开。失败率按独立尝试计算；完成率按玩家首次进入后的完成计算，两者不能混用。广告收入、展示与填充率以平台报表对照，不预设收益承诺。

先观察前 12 关及 L072、L078、L100 的真实操作：玩家能否理解两次点击、候选分页是否增加无关记忆负担、失误是否来自推理而非误触、失败时是否知道可免费重开。再按章校准预算，优先修布局、教学和辨色，再调整参数。变更需同步数据、文档和内容版本。

发布前须逐关人工审查色路合理性、替代排列、颜色可辨性与节奏。自动验证证明内容守恒、预算可行和证解可执行，不证明真人难度、唯一感知答案或广告转化。
