# 《拾色之间》开发状态

日期：2026-10-28。当前版本 **1.1.0，自动回归、实际Web、Cocos构建、抖音工具首页及官方预览已验证**。唯一现行规则见[GAME_DESIGN.md](GAME_DESIGN.md)，运行题库迁移为 `data/levels/levels.v0.6.json`：schema4.1.0、content0.6.0。下面明确区分本轮改动与此前1.0.0证据，不能把旧包、旧预览或旧测试直接算作新版通过。

## 1.1.0 本轮改动范围

- 已填色块可以收回下方任意空候选槽；没有永久绑定的归还位置。候选槽不压缩、不自动重排，支持指定空槽及自动收回入口。
- 点睛先提取正确块腾空，再将错误占位块收回可用候选空槽，最后归位锁定，保持整个事务的守恒；撤销与存档按实际占位恢复。
- 前12关重做结构与采样：从转弯单轨到3×3双向题、分支耦合，再到4×4；首关7格/5候选。第13关起保留认可目标基线。
- 百关候选采用更严格的确定性洗牌：不为目标正序或倒序，至少75%错位，最长正反连续段≤2，相邻目标对比例≤35%，超过4096次拒绝导出。
- 前12关启用独立成绩代次expanded-0.6，保留钱包与库存，旧简单题最佳分不阻挡新版奖励；新代次内仍按最佳提升差额防刷。
- 新增专用WinPanel与Image透明庆祝色环：插画、超大得分、积分到账条、用时/操作两列统计、视频双倍次按钮、下一关主按钮和首页轻链接。

加载8+、首页、编号关卡、动画教程、积分商店、全关倒计时、超时复活及三类广告事务继续沿用现行设计。具体接口和规则以源码与[开发计划](DEVELOPMENT_PLAN.md)为准。
